Recipients WhatsApp / email

Tick the box at the start of a row to select that recipient for Send WhatsApp / Send email (a test message through CallMeBot or your email server). A recipient gets WhatsApp when the phone and key are filled in, and email when the address is filled in. WhatsApp uses CallMeBot: each person sends “I allow callmebot to send me messages” to +34 644 51 95 23 from their phone and gets their own API key.

Daily summary:

One message is sent every day between 14:00 and 14:05 with the fixed prices from 14:00 to 14:00 the next day: the summary, then one line for each time the price goes up to the high limit or down to the low limit. Under Recipients you can add up to 3 extra send times: the same message is then also sent at those times, with the prices from that time to the same time the next day (before 14:00 the next day is not fixed yet, so it then ends at midnight).
