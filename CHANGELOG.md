# Changelog

Format follows [Keep a Changelog](https://keepachangelog.com/); versions follow [SemVer](https://semver.org/).

## [1.0.0] - 2026-11-13
First public release.
- 15-minute Nord Pool spot prices, week-ahead estimate, wind power and weather.
- Three layouts (Signal, Studio, Calm), price breakdown, cost helper, consumption import.
- WhatsApp and email alarms; Docker, local server and standalone modes.
- Images published to GitHub Container Registry; landing page on GitHub Pages.
